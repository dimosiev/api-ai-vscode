## 1. Что это такое

**dimosi** — помощник-программист внутри VS Code. Вы пишете задачу обычными словами, например «сделай страницу с формой обратной связи». Агент сам читает файлы проекта, создаёт новые, правит существующие и запускает команды.

Агент **не привязан к одной компании**. Вы сами выбираете сервис и платите ему напрямую по своему API-ключу:

| Сервис | Что это |
|---|---|
| **Anthropic** | Модели Claude напрямую от разработчика |
| **OpenAI** | Модели GPT напрямую от разработчика |
| **Polza AI** | Российский агрегатор: Claude, GPT, DeepSeek и сотни других моделей, оплата в рублях |
| **OpenRouter** | Международный агрегатор моделей |
| **DeepSeek** | Модели DeepSeek |
| **Ollama** | Бесплатная нейросеть, которая работает на вашем компьютере |
| **Custom** | Любой другой сервис, совместимый с OpenAI API |

Комплект состоит из двух файлов в папке `dist` проекта:
- **`dimosi-0.3.0.vsix`** — расширение для VS Code. Это основной способ работы.
- **`dimosi-cli-0.3.0.tgz`** — версия для терминала. Нужна, только если хотите работать в окне терминала.

## 2. Что понадобится

1. **VS Code версии 1.140 или новее.** Проверить: меню **Code → About Visual Studio Code** (Windows: **Help → About**). Обновить: **Code → Check for Updates…**
2. **API-ключ** хотя бы одного сервиса ([раздел 6](#6-где-взять-api-ключ)). Для Ollama ключ не нужен.
3. **Интернет** (кроме Ollama).

## 3. Переход со старой версии (API AI Agent)

Если у вас стояла первая версия под названием **API AI Agent**, сделайте следующее. Новая версия — отдельное расширение, поэтому ключ нужно перенести.

1. **Сохраните ключи из старой версии** (если не помните ключ наизусть):
   1. `Cmd+Shift+P` → наберите **API AI: Экспортировать ключи в файл…** → Enter.
   2. Придумайте пароль и повторите его.
   3. Сохраните файл, например на Рабочий стол.
2. **Удалите старую версию:** панель **Extensions** (`Cmd+Shift+X`) → найдите **API AI Agent** → значок шестерёнки → **Uninstall**.
3. **Установите dimosi** ([раздел 4](#4-установка)).
4. **Загрузите ключи:** `Cmd+Shift+P` → **dimosi: Импортировать ключи из файла…** → выберите файл → введите пароль. Старый файл подходит, конвертировать его не нужно.
   - Можно и проще: ввести ключ Polza AI заново ([раздел 5](#5-первый-запуск-сервис-ключ-модель)).

## 4. Установка

1. Откройте VS Code.
2. Нажмите `Cmd+Shift+X` (Windows: `Ctrl+Shift+X`) — откроется панель расширений.
3. Вверху панели нажмите **«…»** (три точки) → **Install from VSIX…**
4. Выберите файл `dimosi-0.3.0.vsix` (в папке `dist` проекта). На Mac удобно так: в окне выбора нажмите `Cmd+Shift+G`, вставьте путь к папке и нажмите Enter.
5. Дождитесь сообщения об установке. Если VS Code предложит перезагрузить окно, согласитесь.

На левой вертикальной панели появится **ваш логотип** — это панель dimosi.

> Устанавливать вручную нужно только один раз: дальше dimosi обновляется сам ([раздел 14а](#14а-обновления)).

## 5. Первый запуск: сервис, ключ, модель

1. **Откройте папку проекта:** **File → Open Folder…** (Файл → Открыть папку). Подойдёт и пустая папка. Для первого знакомства лучше взять отдельную тестовую папку.
2. **Откройте панель dimosi:** нажмите логотип на левой панели.
3. **Подключите нейросеть.** Если ключей ещё нет, на экране приветствия будет кнопка **«Выбрать сервис и ввести ключ»**. Нажмите её:
   1. выберите сервис, например **Polza AI**;
   2. вставьте API-ключ (`Cmd+V`) и нажмите **Enter** — вместо символов будут точки, так и задумано;
   3. выберите модель из списка (можно начать печатать для поиска). Пометка **«рекомендуется»** — хороший выбор по умолчанию.
4. Вверху панели появятся название сервиса и модели. Готово.

**Попробуйте:** нажмите на один из примеров на экране приветствия или напишите свою задачу и нажмите **Enter**.

## 6. Где взять API-ключ

API-ключ — длинная строка вроде `sk-...`. Она подтверждает, что запросы идут от вас, а сервис списывает деньги с вашего баланса. Обращайтесь с ключом как с паролем от кошелька.

| Сервис | Где получить ключ | Оплата |
|---|---|---|
| **Polza AI** | [polza.ai](https://polza.ai) → личный кабинет → **API-ключи** ([прямая ссылка](https://polza.ai/dashboard/api-keys)) | В рублях, в личном кабинете |
| **Anthropic** | [console.anthropic.com](https://console.anthropic.com) → **API Keys** → **Create Key** | Раздел **Billing** |
| **OpenAI** | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) | Раздел **Billing** |
| **OpenRouter** | [openrouter.ai/keys](https://openrouter.ai/keys) | Раздел **Credits** |
| **DeepSeek** | [platform.deepseek.com](https://platform.deepseek.com) → **API keys** | Раздел **Top up** |
| **Ollama** | Ключ не нужен | Бесплатно |

**Совет:** через **Polza AI** доступны и Claude, и GPT, и DeepSeek с оплатой в рублях. Модели называются так: `anthropic/claude-opus-5.5`, `openai/gpt-6.1-sol`, `deepseek/deepseek-v4-flash`.

## 7. Как работать с агентом

Пишите задачу так, как объясняли бы живому программисту. Чем конкретнее, тем лучше:

- «Расскажи, что делает этот проект и как его запустить».
- «Добавь на страницу contacts.html форму: имя, телефон, сообщение».
- «При запуске `npm start` появляется ошибка — найди причину и исправь».

Агент помнит весь разговор, поэтому можно уточнять: «теперь сделай кнопку синей».

**Элементы панели:**

| Элемент | Что делает |
|---|---|
| Логотип и «Сервис / модель» вверху | Нажмите на название модели, чтобы сменить сервис или модель |
| Плашка **«С подтверждением»** | Включает и выключает подтверждения ([раздел 8](#8-подтверждения-и-откат-изменений)) |
| **+** в заголовке панели | Новый чат: агент забывает разговор |
| **Книга** в заголовке | Правила для агента ([раздел 9](#9-правила-для-агента)) |
| **Сервер** в заголовке | Выбрать сервис и модель |
| **Ключ** в заголовке | Ввести или заменить API-ключ |
| **Скрепка** под полем ввода | Прикрепить файлы и картинки |
| **Стоп** (во время работы) | Немедленно остановить агента |

Строки с иконками в чате — это действия агента: чтение файла, поиск, команда. Зелёная точка справа — успешно, красная — ошибка. Нажмите на стрелку под строкой, чтобы увидеть подробности.

Кнопка **«Копировать»** появляется при наведении на блок кода в ответе.

## 8. Подтверждения и откат изменений

### Подтверждения прямо в чате

По умолчанию агент **ничего не меняет без вашего разрешения.**

**Изменение файла.** В чате появляется карточка, выделенная синей рамкой:
- название файла и счётчик строк: `+3 −1`;
- изменения построчно: **зелёным** — добавленное, **красным** — удалённое, слева номера строк;
- кнопки:
  - **Применить** — сохранить изменение;
  - **Отклонить** — не сохранять (агент узнает об отказе и спросит, как поступить);
  - **Всегда** — больше не спрашивать про файлы до конца сессии;
  - **Открыть сравнение** — показать старую и новую версии рядом в большом окне.

**Команда** (например, установка библиотеки или запуск тестов). Карточка с текстом команды и кнопками **Выполнить / Отклонить / Всегда**. Если не понимаете, что делает команда, нажмите **Отклонить** и спросите агента в чате.

Пока карточка ждёт ответа, внизу панели написано «Ждёт вашего решения…». Если панель была свёрнута, она откроется сама.

### Откат: вернуть как было

После каждой задачи, в которой агент менял файлы, появляется карточка **«Изменено файлов: N»**:
- нажмите на имя файла, чтобы открыть его;
- **Откатить** рядом с файлом — вернуть версию до этой задачи (созданный агентом файл будет удалён);
- **Откатить все** — отменить все изменения этой задачи.

Если вы сами успели поправить файл после агента, dimosi сначала спросит, точно ли откатывать: ваши правки в этом файле пропадут.

> Откат работает, пока открыт этот чат. После «Нового чата» или перезапуска VS Code карточки исчезают. Для серьёзных проектов дополнительно используйте git.

### Режим без подтверждений

Нажмите плашку **«С подтверждением»** вверху и подтвердите. Плашка станет красной: **«Без подтверждений»**, и агент будет действовать сам. Включайте этот режим только в тех папках, которые не жалко. Повторное нажатие возвращает подтверждения.

## 9. Правила для агента

Правила — ваши постоянные указания: на каком языке отвечать, какой стиль кода использовать, что нельзя трогать. **Агент перечитывает их перед каждым ответом**, поэтому изменения действуют сразу, без нового чата.

### Два вида правил

| Вид | Где лежит | Для чего |
|---|---|---|
| **Глобальные** | `~/.config/dimosi/rules.md` (Windows: `%APPDATA%\dimosi\rules.md`) | Ваши общие привычки — для всех проектов |
| **Правила проекта** | В папке проекта: `.dimosi/rules.md`, файлы в `.dimosi/rules/`, а также `AGENTS.md` и `CLAUDE.md` | Особенности конкретного проекта |

При конфликте приоритет у правил проекта.

### Как создать

Нажмите значок **книги** вверху панели (или плашку **«Правила»** над полем ввода):
- **Открыть глобальные правила** — откроется файл с готовым шаблоном. Впишите свои правила, по одному на строку, и сохраните (`Cmd+S`).
- **Создать правила проекта** — создаст `.dimosi/rules.md` с разделами «О проекте», «Стиль кода», «Запреты», «Команды». Заполните их.
- **Сгенерировать правила по проекту** — агент сам изучит проект и напишет правила. Запись файла вы подтвердите как обычно. Потом проверьте и поправьте текст.

Над полем ввода всегда видна плашка **«Правила: N»** — сколько файлов правил действует сейчас. Наведите на неё, чтобы увидеть список. «Без правил» значит, что правил пока нет.

**Пример глобальных правил:**
```
- Отвечай на русском языке.
- Перед изменениями кратко объясняй план.
- Комментарии в коде пиши по-русски.
- Не удаляй файлы без явной просьбы.
```

> Правила не должны быть огромными: учитывается до 30 тысяч символов на файл и до 80 тысяч всего. Если файл больше, в списке правил он отмечен «обрезано».

## 10. Вложения: файлы и картинки

К сообщению можно приложить файлы и картинки. Вложения появляются плашками над полем ввода, а **×** на плашке убирает вложение.

| Способ | Как |
|---|---|
| **Скрепка** | Кнопка под полем ввода → выберите один или несколько файлов |
| **@** | Наберите `@` и начало имени файла → выберите из списка стрелками и Enter (или мышкой) |
| **Открытый файл** | Над полем ввода есть пунктирная плашка с именем открытого файла — нажмите её |
| **Скриншот** | Скопируйте картинку (например, `Cmd+Ctrl+Shift+4` на Mac) и вставьте в поле ввода `Cmd+V` |
| **Перетаскивание** | Картинки перетаскиваются откуда угодно. Файлы из списка VS Code — с зажатым **Shift** |

Ограничения: текстовые файлы до 100 тысяч символов (больше — обрезаются), картинки PNG, JPG, GIF, WebP до 5 МБ.

**Картинки понимают не все модели.** Claude, GPT и большинство современных моделей понимают. Если модель не умеет, вы увидите сообщение об этом — выберите другую модель.

## 11. Действия из редактора

**Выделенный код:** выделите фрагмент в редакторе → правая кнопка мыши → **dimosi** →
- **Объяснить** — агент объяснит, что делает код, ничего не меняя;
- **Исправить** — найдёт и исправит ошибки (с подтверждением);
- **Улучшить** — сделает код понятнее и надёжнее, не меняя поведения;
- **Добавить в чат** — прикрепит фрагмент к сообщению, а задачу вы напишете сами.

**Ошибки в коде:** если VS Code подчеркнул ошибку, наведите на неё или нажмите на лампочку 💡 → **Исправить с помощью dimosi**. Агент получит текст ошибки и код вокруг неё.

## 12. Ход работы и стоимость

- **План.** Для задач из нескольких шагов агент показывает карточку **«План»** с прогрессом: ✓ — сделано, синяя точка — делается сейчас.
- **Что происходит сейчас.** Внизу панели во время работы пульсирует линия из логотипа и написано текущее действие («Чтение index.html…», «Ждёт вашего решения…») и время.
- **Токены и стоимость.** Справа внизу: `токены 18 тыс. → 950 · ≈ 2.30 ₽ · контекст 18 тыс.`
  - первое число — сколько отправлено нейросети, второе — сколько она написала;
  - **стоимость**: для Polza AI это **точная сумма в рублях**, которую сообщает сам сервис; для Anthropic и OpenRouter — оценка в долларах по тарифу; для остальных — только токены;
  - **контекст** — размер разговора. Если он становится оранжевым, разговор слишком длинный: ответы дороже и медленнее. Для новой задачи начните **новый чат** (+).

**Как экономить:** новая задача — новый чат; для простых задач выбирайте модели подешевле (в названии часто есть `mini`, `flash`, `haiku`, `sonnet`). Для Claude через Anthropic включено автоматическое кэширование: повторно отправляемая история стоит примерно в 10 раз дешевле.

## 13. Смена сервиса, модели и ключей

Все команды — через палитру: `Cmd+Shift+P` (Windows: `Ctrl+Shift+P`), начните печатать **dimosi**:

| Команда | Что делает |
|---|---|
| **dimosi: Выбрать сервис и модель** | Сменить сервис и модель |
| **dimosi: Ввести API-ключ** | Добавить или заменить ключ |
| **dimosi: Удалить API-ключ** | Удалить сохранённый ключ |
| **dimosi: Экспортировать ключи в файл…** | Сохранить ключи в зашифрованный файл |
| **dimosi: Импортировать ключи из файла…** | Загрузить ключи из файла |
| **dimosi: Правила для агента** | Список правил и действия с ними |
| **dimosi: Новый чат** | Начать разговор заново |
| **dimosi: Переключить подтверждения действий** | Вкл/выкл подтверждения |

Ключи нескольких сервисов можно хранить одновременно и переключаться в любой момент — разговор сохраняется.

**Настройки:** **Code → Settings → Settings** (Windows: **File → Preferences → Settings**), в поиске `dimosi`. Например, **Max Steps** — сколько шагов агент делает на одну задачу (по умолчанию 50).

## 14. Перенос на другой компьютер

**Возьмите с собой:**
1. `dimosi-0.3.0.vsix` (из папки `dist`).
2. Файл с ключами: `Cmd+Shift+P` → **dimosi: Экспортировать ключи в файл…** → пароль → сохранить (`dimosi-keys.aienc`). **Запомните пароль** — восстановить его нельзя.
3. Глобальные правила, если вы их писали: файл `~/.config/dimosi/rules.md`. Чтобы найти его: **книга** → **Открыть глобальные правила** → правой кнопкой по вкладке файла → **Reveal in Finder**.
4. По желанию — `dimosi-cli-0.3.0.tgz` для терминала.

**На новом компьютере:**
1. Установите или обновите VS Code (1.140+).
2. Установите расширение из `.vsix` ([раздел 4](#4-установка)).
3. `Cmd+Shift+P` → **dimosi: Импортировать ключи из файла…** → файл → пароль.
4. Глобальные правила: **книга** → **Открыть глобальные правила** → замените текст своим → сохраните.
5. Откройте папку проекта, выберите сервис и модель. Правила проекта лежат в самом проекте (`.dimosi/`) и переезжают вместе с ним.

## 14а. Обновления

**Расширение обновляется само.** Примерно раз в 6 часов (и через полминуты после запуска VS Code) dimosi проверяет сервер обновлений. Найдя новую версию, он:
1. скачивает её и **проверяет контрольную сумму** (повреждённый или подменённый файл не установится);
2. если агент в этот момент работает над задачей — ждёт, пока он закончит;
3. устанавливает и показывает уведомление «dimosi обновлён до версии … — **Перезагрузить**». Нажмите, и через пару секунд работает новая версия. Ключи, правила и настройки сохраняются.

Проверить вручную: `Cmd+Shift+P` → **dimosi: Проверить обновления**.
Отключить автообновление: настройки → `dimosi` → снять галочку **Auto Update**.

**Терминальная версия** раз в сутки при запуске сообщает о новой версии. Обновление: `dimosi update` (на Mac может понадобиться `sudo dimosi update`).

> Обновления раздаются по секретной ссылке с сервера d-osi.ru. Ссылка зашита в установочный файл, поэтому передавайте `.vsix` только тем, кому хотите давать обновления.

## 15. Работа из терминала (необязательно)

1. Установите **Node.js 22 или новее** с [nodejs.org](https://nodejs.org) (кнопка **LTS**).
2. В терминале, в папке с файлом: `npm install -g ./dimosi-cli-0.3.0.tgz` (на Mac может понадобиться `sudo` в начале).
3. Проверка: `dimosi --help`.

Основные команды:
```
dimosi keys set polza                         # сохранить ключ (спросит ключ и пароль хранилища)
dimosi keys import ~/Desktop/dimosi-keys.aienc
dimosi use polza anthropic/claude-opus-5.5    # сервис и модель по умолчанию
dimosi rules global                           # создать файл глобальных правил
cd путь/к/проекту && dimosi                   # открыть чат в папке проекта
dimosi "найди и исправь ошибку в app.js"      # сразу дать задачу
```

Терминальная версия читает те же правила, показывает план, изменения (зелёный/красный) и стоимость. Внутри чата: `/model`, `/models`, `/provider`, `/key`, `/rules`, `/auto`, `/ask`, `/clear`, `/help`, `/exit`. **Ctrl+C** во время работы останавливает агента.

Если стояла старая терминальная версия (`ai-agent`), её настройки и ключи переносятся автоматически при первом запуске `dimosi`. Старую версию можно удалить: `npm uninstall -g @api-ai/cli`.

## 16. Свой сервер или локальная нейросеть

**Ollama (бесплатно, на своём компьютере):**
1. Установите с [ollama.com](https://ollama.com).
2. В терминале: `ollama pull qwen3-coder` (или другую модель). Нужен мощный компьютер.
3. dimosi: **Выбрать сервис и модель** → **Ollama (local)** → модель.

Локальные модели слабее облачных и иногда плохо справляются с инструментами агента.

**Любой OpenAI-совместимый сервис (custom):** **Выбрать сервис и модель** → **Custom OpenAI-compatible** → адрес API (например, `http://localhost:1234/v1` для LM Studio) → при необходимости ключ → модель.

## 17. Безопасность

- **Ключи** хранятся в защищённом хранилище системы: «Связка ключей» на Mac, «Диспетчер учётных данных» на Windows.
- **Файл экспорта** (`.aienc`) зашифрован (AES-256). Без пароля он бесполезен, но всё равно не публикуйте его.
- **Агент видит только открытую папку**, но содержимое прочитанных и прикреплённых файлов отправляется выбранному сервису. Не открывайте агентом папки с паролями и личными документами.
- **Не отключайте подтверждения** в важных проектах: команды выполняются с правами вашей учётной записи.
- **Если ключ утёк** — удалите его в кабинете сервиса и создайте новый.

## 18. Если что-то не работает

| Что видно | Что делать |
|---|---|
| «Откройте папку проекта» | **File → Open Folder…** или кнопка в сообщении |
| «Нет API-ключа для …» | Кнопка **Ввести ключ** в сообщении |
| «Неверный API-ключ (401)» | Ключ неверный или удалён. Создайте новый в кабинете сервиса и введите заново |
| «Сервис требует оплату (402)» | Пополните баланс |
| «Модель или адрес не найдены (404)» | Выберите модель из списка (нажмите на название модели вверху) |
| «Слишком много запросов (429)» | Подождите минуту или проверьте тариф |
| «Сервис временно недоступен (5xx)» | Повторите через минуту |
| «Нет связи с сервисом» | Проверьте интернет (для Ollama — что Ollama запущена) |
| «Разговор стал слишком длинным» | Начните новый чат (+) |
| «Эта модель не принимает картинки» | Уберите картинку или выберите другую модель |
| «Агент сделал 50 шагов и остановился» | Напишите «продолжай» или увеличьте **Max Steps** в настройках |
| Агент не слушается правил | Проверьте плашку **«Правила: N»**: если «Без правил», файл не найден. Правила должны лежать в папке, открытой в VS Code |
| Карточка подтверждения не реагирует | Нажмите **Стоп** и повторите задачу |
| «Неверный пароль» при импорте | Нужен пароль, заданный при экспорте. Если забыт — экспортируйте заново на старом компьютере |
| Логотипа нет на левой панели | **Extensions** → вкладка **Installed** → проверьте, что «dimosi» установлен и включён, перезапустите VS Code |
| Ошибка о версии при установке `.vsix` | Обновите VS Code до 1.140+ |
| Обновление не пришло | `Cmd+Shift+P` → **dimosi: Проверить обновления** — покажет причину. Проверьте, что в настройках включено **Auto Update** |
| `dimosi: command not found` в терминале | Установите CLI ([раздел 15](#15-работа-из-терминала-необязательно)) и перезапустите терминал |

## 19. Для разработчика: как пересобрать

Нужен Node.js 22.12+.

```
cd api-ai
npm install          # зависимости
npm test             # автотесты (ядро, откат, интерфейс панели)
npm run typecheck    # проверка типов
npm run package      # dist/dimosi-<версия>.vsix и dist/dimosi-cli-<версия>.tgz
```

**Выпуск новой версии** (установленные копии обновятся сами):
```
npm run release                                  # 0.3.0 → 0.3.1
npm run release -- 0.4.0 --notes "Что нового"   # своя версия и описание
git commit -am "Release 0.4.0" && git push
```
Скрипт поднимает версию, прогоняет тесты и проверку типов, собирает, считает контрольные суммы, заливает файлы на сервер (`latest.json` — последним) и проверяет, что новая версия скачивается по ссылке.

Для выпуска нужен файл `release.config.json` в корне проекта (образец — `release.config.example.json`). В нём секретный адрес обновлений и SSH-доступ. **Файл в git не попадает** — не коммитьте его: репозиторий публичный. Сохраните копию файла рядом с ключами сервера: без него выпускать обновления на тот же адрес нельзя.

Сервер: файлы лежат в `/var/www/dimosi-updates` (юзер `deploy`), раздаёт их nginx сайта d-osi.ru отдельным блоком `location` (см. `deploy/nginx/d-osi.ru.conf` в проекте сайта).

Устройство:
```
packages/core      ядро: сервисы нейросетей, цикл агента, инструменты, правила, стоимость, шифрование ключей
packages/vscode    расширение: src/ — логика, webview/ — интерфейс панели, media/ — стили и логотип
packages/cli       программа для терминала
```

- **Новый сервис:** добавить в `PRESETS` (`packages/core/src/providers/presets.ts`) и в `enum` настройки `dimosi.provider` (`packages/vscode/package.json`).
- **Логотип и цвета:** `packages/vscode/media/brand/` (иконки) и переменная `--brand` в `packages/vscode/media/chat.css`.
- **Отладка:** откройте `packages/vscode` в VS Code, `npm run build`, затем `F5`.
