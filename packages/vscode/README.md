# dimosi

Агент для программирования прямо в VS Code. Работает через ваши API-ключи: Anthropic (Claude), OpenAI, Polza AI, OpenRouter, TeamoRouter, DeepSeek, локальный Ollama или любой OpenAI-совместимый сервер.

- **Правила.** Глобальные правила и правила проекта (`AGENTS.md`, `.dimosi/rules.md`, `.dimosi/rules/*.md`) агент читает перед каждым ответом.
- **Изменения в чате.** Каждая правка показывается цветным diff прямо в чате с кнопками «Применить / Отклонить». После задачи — список изменённых файлов с откатом.
- **Ход работы.** План задачи, текущее действие, токены и стоимость (в рублях для Polza AI).
- **Вложения.** Файлы, картинки, скриншоты из буфера, упоминание файлов через `@`.
- **Из редактора.** Выделите код → правая кнопка → dimosi → «Объяснить / Исправить / Улучшить / Добавить в чат». Лампочка на ошибках → «Исправить с помощью dimosi».
- **Ключи** хранятся в защищённом хранилище системы и переносятся на другой компьютер зашифрованным файлом.

Полное руководство — `docs/РУКОВОДСТВО.md` в папке проекта.
