# dimosi

Переносимый агент для программирования: работает в VS Code и в терминале через ваши API-ключи — Anthropic (Claude), OpenAI, Polza AI, OpenRouter, TeamoRouter, DeepSeek, Ollama или любой OpenAI-совместимый сервер.

**Руководство пользователя: [docs/РУКОВОДСТВО.md](docs/РУКОВОДСТВО.md)**

## Сборка

```
npm install
npm run package
```

Результат — в `dist/`:
- `dimosi-<версия>.vsix` — расширение VS Code (Extensions → … → Install from VSIX…);
- `dimosi-cli-<версия>.tgz` — агент для терминала (`npm install -g ./dimosi-cli-<версия>.tgz`, команда `dimosi`).

## Возможности

- Чат в боковой панели; ответы приходят потоком, Markdown.
- Правила: глобальные (`~/.config/dimosi/rules.md`) и проектные (`AGENTS.md`, `CLAUDE.md`, `.dimosi/rules.md`, `.dimosi/rules/*.md`). Перечитываются на каждом сообщении.
- Подтверждение каждой правки цветным diff прямо в чате; откат изменений задачи по файлам или целиком.
- Открытые в редакторе файлы правятся через редактор: учитываются несохранённые правки, Cmd+Z отменяет правку агента.
- Последний чат папки переживает перезагрузку окна вместе с карточками отката. «Новый чат» не стирает прежний: до 30 прошлых чатов папки можно открыть снова или удалить (значок часов, команда «dimosi: Прошлые чаты…»).
- Правила проекта (`AGENTS.md`, `CLAUDE.md`, `.dimosi/`) подключаются только после «Доверять»; `.vscode/`, `.github/workflows/`, `package.json`, `.husky/`, `.envrc`, `.devcontainer/` и сами правила всегда с отдельным подтверждением; скрытые символы в команде или изменении показываются и предупреждаются.
- Папки вне проекта: агенту можно открыть другие папки, каждую только для чтения или для чтения и записи (строка «Доступ» в панели, в терминале `--read-dir` и `--write-dir`). Инструменты и песочница пользуются одним списком; папки с ключами и секретные файлы закрыты всегда.
- Чтение веб-страниц (документация, статьи): только с разрешения для каждого сайта, только https, без доступа к локальной сети; текст страницы для агента — данные, а не указания.
- Создание картинок: агент рисует через модель изображений Polza AI (инструмент `generate_image`), файл сохраняется в проект и показывается в чате; каждая картинка платная и подтверждается отдельно, даже в режиме без подтверждений.
- Помощники (субагенты): агент поручает разведку отдельной модели (можно другого сервиса, выбирается в команде «dimosi: Помощники…»); помощник только читает, запуск спрашивается один раз («Всегда» запоминается). Встроенный помощник `explorer` работает сразу. Настройка `dimosi.subagents`, в терминале — поле `subagents` в `config.json`.
- Усердие модели (настройка `dimosi.effort`, команда «dimosi: Усердие модели…», в терминале `--effort`): насколько старательно модель работает над ответом. По умолчанию выключено. Действует с Anthropic, Polza AI, OpenRouter, OpenAI и TeamoRouter (Claude).
- Режим «Сначала план»: агент изучает задачу и показывает план, ничего не меняя; работа начинается после «Выполнить план».
- В VS Code агент после каждой правки получает ошибки редактора по изменённому файлу и исправляет их сам.
- «Всегда» для команды запоминает её начало (`npm test …`) для этого проекта и между сессиями; команды из нескольких частей запоминаются только целиком; список можно посмотреть и очистить.
- Проверка в настоящем VS Code (`npm run test:vscode`) и выпуск только с коммита с зелёным CI.
- Безопасность команд: на macOS песочница (запись только в проект, временные папки и кэши пакетов; `~/.ssh`, токены, «Документы» и другие личные папки недоступны); опасные команды (`rm -rf`, `git push`, `sudo`…) всегда с отдельным вопросом; команды не видят ключей из окружения; `.env` и другие файлы с секретами агент не читает, не меняет и не прикрепляет, а команды в песочнице не могут их прочитать; из песочницы нельзя запустить программу через `open` или AppleScript.
- Журнал без ключей и текста переписки («Вывод → dimosi», `~/.config/dimosi/dimosi.log`) и команда «Сообщить о проблеме».
- План задачи, текущее действие, токены и стоимость. Для Polza AI — точная сумма в рублях из ответа сервиса.
- Кэш для моделей Claude напрямую через Anthropic и через Polza AI / OpenRouter; доля попаданий в кэш видна в журнале (`hit N%`).
- Вложения: файлы, картинки, вставка скриншотов, `@`-упоминания файлов.
- Действия из редактора: «Объяснить / Исправить / Улучшить / Добавить в чат», лампочка «Исправить с помощью dimosi».
- Ключи — в системном хранилище (Keychain / Credential Manager); перенос — зашифрованным файлом (AES-256-GCM + scrypt).

## Обновления

Расширение и CLI обновляются с сервера владельца: `npm run release` публикует новую версию, установленные копии ставят её сами, только если манифест подписан ключом владельца (Ed25519, открытый ключ в `packages/core/src/update-key.ts`, закрытый — в менеджере паролей; создаётся `npm run signing-key`), и сверяют SHA-256 файла. Адрес сервера задаётся в `release.config.json` (не в git, образец — `release.config.example.json`) и подставляется при сборке; без него самообновление выключено.

## Разработка

Устройство кода, правила, которые нельзя ломать, и рецепты типовых задач: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Правила работы для ИИ-агента: [CLAUDE.md](CLAUDE.md).

```
npm test            # vitest: ядро, откат, панель (jsdom), сквозные тесты VS Code и CLI с фейковым сервером
npm run typecheck   # tsc: core, cli, vscode, webview
npm run build
```

| Пакет | Назначение |
|---|---|
| `packages/core` | Провайдеры (Anthropic SDK, OpenAI SDK), цикл агента, инструменты, правила, стоимость, шифрование ключей |
| `packages/vscode` | Расширение: `src/` (extension host), `webview/` (панель чата), `media/` (стили, бренд) |
| `packages/cli` | Терминальный REPL |
